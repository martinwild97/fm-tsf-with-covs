# Benchmark Code for Thesis Experiments

This directory contains the source code used to run the empirical benchmark for the Master's Thesis: *"Foundation Models for Time Series Forecasting with Exogenous Variables: A Survey and Benchmark"*. This framework is designed to be a comprehensive tool for evaluating and comparing time series forecasting models.

For the complete setup, the **[Model API](../fm-api/README.md)** must be running as well.

---

## 🎯 Project Goal

The primary goal of this benchmark is to provide a reproducible framework for:
1.  **Forecasting:** Systematically generating forecasts from various models (Foundation Models, DL, ML, Statistical) across multiple datasets and scenarios.
2.  **Evaluating:** Calculating a wide range of accuracy and performance metrics.
3.  **Analyzing:** Comparing model performance, with a special focus on the impact of integrating exogenous variables.

For a comprehensive understanding of the project's motivation and findings, please refer to the **[main repository README](../../README.md)** and the full **[Master's Thesis PDF](../../Wild-2025-Foundation-Models-TSF-Exogenous-Variables.pdf)**.

---

## ⚙️ The Benchmark Workflow

The entire process is automated through the main script and can be broken down into the following stages:

1.  **Data Preprocessing:** Raw datasets from `data/raw_datasets/` are cleaned, standardized, and saved into a unified format in `data/prepared_datasets/`. This preprocessing step is handled by the `notebooks/dataset_preprocessing.ipynb` notebook.
2.  **Sample Generation:** The code defines a set of experimental "samples" based on the datasets, forecast horizons, and rolling windows, which are saved in `data/sample_info.csv`.
3.  **Forecasting Execution:** The `src/main.py` script iterates through all models and covariate scenarios for each sample. It calls the CPU-native models directly and sends requests to the Model API for GPU-based models. All forecasts are saved in `data/forecasts/`.
4.  **Evaluation:** After forecasting, the script calculates performance metrics for all results and saves them to `data/metrics.csv`.
5.  **Analysis & Visualization:** The results can be analyzed and the plots from the thesis can be reproduced using the Jupyter notebooks in the `notebooks/` directory.

## 🚀 Running the Experiments

### Prerequisites
* **Docker** and **Docker Compose** are required.
* The **[Model API](../fm-api/)** must be running in a separate terminal.

### Steps to Run
The entire environment is containerized for easy and reproducible execution.

1.  **Build the Docker image:** From within this directory (`code/benchmark/`), run:
    ```bash
    docker build -t thesis-benchmark .
    ```

2.  **Run the container:**
    ```bash
    docker run -v ./data:/app/data -v ./logs:/app/logs thesis-benchmark
    ```
    * The `-v` flags mount the `data` and `logs` directories, so your results are saved on your host machine and not lost when the container stops.
    * This will start the complete forecasting and evaluation pipeline as defined in the `run.sh` script. The process can take a very long time to complete.

## 📂 Directory Structure Explained

* **`data/`**: The central hub for all data and results.
    * **`raw_datasets/`**: The original, untouched dataset files.
    * **`prepared_datasets/`**: Cleaned and standardized datasets used by the benchmark.
    * **`forecasts/`**: Stores all generated forecasts (`data.csv`) and their corresponding metadata (`meta.csv`).
    * **`plots/`**: Contains all plots and figures generated for the thesis.
    * **`metrics.csv`**: The final, aggregated performance metrics for all models and scenarios.
    * **`*.csv`**: Other metadata files defining datasets, samples, and selection results.
* **`logs/`**: Contains detailed logs for forecasting and evaluation runs, useful for debugging.
* **`notebooks/`**: Jupyter notebooks for data preprocessing, results analysis, and plot generation.
    * `dataset_preprocessing.ipynb`: Use this to process raw datasets.
    * `04evaluation.ipynb`: Use this to analyze results and reproduce thesis figures.
* **`src/`**: The main Python source code for the benchmark.
    * **`data/`**: Modules for data loading, sampling, and covariate selection.
    * **`evaluation/`**: Modules for calculating and saving metrics.
    * **`models/`**: Wrappers and API clients for all forecasting models.
    * **`main.py`**: The main entry point that orchestrates the entire workflow.

## 🔬 Reproducing the Results

To analyze the results and reproduce the figures and statistical tests from the thesis, simply run the **`notebooks/04evaluation.ipynb`** notebook. Ensure that the `data/forecasts/` and `data/metrics.csv` files have been generated by a complete run of the benchmark first.
